# Style Studio — React E-Commerce Demo

A responsive student e-commerce front-end built with React and Vite.

## Features
- Product photos and product detail popups
- Category filters: Clothing, Shoes, Bags, Glasses, Beauty
- Product search and price sorting
- Wishlist buttons
- Shopping cart with quantity controls and subtotal
- Demo checkout form (no real payment or delivery)

## Run locally
1. Install Node.js.
2. Open this project folder in VS Code.
3. Open Terminal in this folder.
4. Run `npm.cmd install` (PowerShell on Windows).
5. Run `npm.cmd run dev`.
6. Open the `Local` URL shown in the terminal, usually `http://localhost:5173/`.

Product images are loaded from Unsplash, so an internet connection is needed to display them. This is a front-end demo; it has no database or real payment processing.
